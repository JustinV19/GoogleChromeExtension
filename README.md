## 1.Einleitung

### 1.1 Ziel der Software
Die Software wurde entwickelt, um Rechnungen von Bestellungen auf der Plattform Cardmarket.com zu erstellen.
Ziel ist es, den Benutzer bei der erstellung der Rechnung zu unterstützen, zusätzlich die Rechnungen in Datei-formaten anzubieten, die für weitere Systeme verwendet werden kann.

### 1.2 Zielgruppe
Die Anwendung richtet sich primär an die Gewerblichen die auf der Webseite Cardmarket.com tätig sind.

## 2.Projektbeschreibung
Gewerbliche nutzer auf der Plattform Cardmarket.com haben keine möglichkeiten eine Rechnung zu erstellen ohne es manuell abtippen zu müssen.
Das soll diese Extension lösen, zusätzlich liefert es die möglichkeit, die Rechnung in ein gewünschten Format zu erstellen, so das die Rechnung zum eigenen System passt.
Den Vorteil liegt dabei das die benutzer es einfacher haben Ihre Buchhaltung zu führen und die möglichkeit zur Automatisierung bietet.
